# FIT COACH Landing Page

A polished static landing page demo for Coach Leo, a Guangzhou personal fitness coach focused on fat loss, muscle gain, and posture improvement. It is built with plain HTML, CSS, and vanilla JavaScript, so it is simple to edit and easy to deploy on GitHub Pages.

## Files

- `index.html` - semantic page structure and content
- `style.css` - responsive dark fitness theme with CSS custom properties
- `script.js` - mobile navigation, FAQ support through native details, reveal animations, and demo form behavior

## Open Locally

Open `index.html` directly in your browser.

You can also run a simple local server from this folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deploy To GitHub Pages

1. Push this folder to a GitHub repository.
2. Go to the repository settings.
3. Open Pages.
4. Choose the branch and root folder.
5. Save and wait for the Pages URL to become available.

## Form Integration Notes

The consultation form is static right now. Comments in `index.html` show where a FormSubmit or Web3Forms endpoint can be connected later.
